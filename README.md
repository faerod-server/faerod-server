# FAEROD oyun sunucusu

Bu klasör yalnızca oyun sunucusunu içerir (odalar, davet linkleri, web sürümü, Android APK indirme).

- Sağlık kontrolü: `/health`
- Açık odalar: `/api/rooms`
- Davet sayfası: `/j/ODAKODU`
- Web / iPhone sürümü: `/`

İsteğe bağlı ortam değişkenleri: `PUBLIC_URL` (ör. https://oyun.faerod.com), `APK_URL`, `WIN_URL` (indirme linkleri başka yerdeyse).
